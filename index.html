Charts — DPS by a stat · DPS by fight length · what each buff is worth

Pick a chart and press Draw chart. DPS by a stat shows how a build's damage grows as one stat on your gear goes up, with everything else as you have set it — for example where more hit stops helping. DPS by fight length shows which build is ahead in short and in long fights. What each raid buff and debuff is worth measures, for one build, what you lose without each one you have on and what you would gain with each one you have off.

Priority (top = checked first)

    APL

    A rule casts a spell when your conditions hold: DoT or buff time left, cooldowns, fight time, boss health, mana, Soul Shards, Demonic Brand charges — combined with "all of", "any of" and "not". A group is a list of actions you can put in the priority as one; a variable is a number or a condition with a name, used in your rules. A rule without a condition is a filler.

        Input / output settings and builds · batch compare

        Input / output: settings and builds

        A code is a line of text you can keep or send to someone. A settings code (starts with WFS1:) holds your stats, fight, buffs, debuffs, consumables, professions and pet settings. A build code (WFB1:) holds one build: talents, pet, weapon stone and priority. Make a code here, or paste one and press Load — settings are applied, a build opens in the build editor. A gear code (WFG1:) from the in-game addon goes into the gear builder.

        Batch compare

        Save several setups (e.g. pre-raid vs raid-buffed), then run them all: every build × race per setup, best race per build. "Add this run" keeps the results in the table as they are.
